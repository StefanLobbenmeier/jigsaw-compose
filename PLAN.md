# Implementation plan

Completed sequentially by four agents:

1. Scaffold a Kotlin Compose Multiplatform app with shared UI, desktop JVM and browser JS targets, Gradle wrapper, and reproducible builds.
2. Implement seeded complementary jigsaw edges, neighbor-only forgiving snapping, connected-group movement, completion and stash ordering, with engine tests.
3. Build playable shared UI, local image import, licensed bundled gallery, color/shape/manual stash controls, reference guide and difficulty options.
4. Review and validate production builds, document controls and limitations, publish a public repository, and automate GitHub Pages deployment.

Possible follow-ups: saved progress, mobile platform targets, rotation, keyboard gameplay, more gallery images and automated browser interaction tests.
